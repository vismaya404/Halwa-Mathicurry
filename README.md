### Project Description

**Halwa & Mathicurry** is a completely unnecessary food-combination analyzer that generates weird food combinations when you enter the name of a food item.

For example, enter **"Halwa"** and our highly questionable food science proudly suggests **"Mathi Curry"**. The project also features an **"Amma Approved™"** Malayalam dialogue to judge your food choices.

### The Problem (that doesn't exist)

Have you ever eaten a food and thought:

> "What is the worst possible food I can combine with this?"

No?

Neither did we.

But we decided this extremely important problem needed a solution anyway.

People around the world are suffering from a severe lack of completely unnecessary food combinations. There was clearly a need to fix this.

### The Solution (that nobody asked for)

Introducing **Halwa & Mathicurry**!

Simply enter a food item and our advanced, totally-not-scientific food analysis system will suggest a weird combination.

The system then provides an **Amma Approved™ Malayalam reaction**, because no food decision is complete without an Amma judging it.

Example:

**Input:**  
Halwa 🍯

**Recommended Combination:**  
Mathi Curry 🐟

**Amma:**  
"അയ്യോ മോളേ, ഹൽവയും മത്തിക്കറിയും കൂടെയോ?! ഇതൊക്കെ ആരുടെ ബുദ്ധിയാ?"

Science has officially failed.

## Implementation

### For Software:

The project is implemented as a simple frontend web application.

The user enters the name of a food item in the input field.

JavaScript checks the entered food against a collection of food combinations.

The application then displays:

1. The entered food
2. A weird food combination
3. A realistic food image
4. An "Amma Approved™" Malayalam dialogue

If the entered food is not available in the predefined list, the application generates a random weird combination.
